# 線表（scheduleView）

ブラウザ上で作業の線表（ガントチャート）を引くツールです。開始日・単位・期間を指定すると点線グリッドのタイムラインが表示され、項目単位のカラーブロックをドラッグで配置・伸縮できます。

- 単一ファイル完結：`scheduleView.html` だけで動きます（ビルド・依存パッケージ・サーバー不要、外部通信なし）
- 入力内容は自動的にこのブラウザへ保存されます

## 起動

`scheduleView.html` をブラウザにドラッグ／ダブルクリックするだけです。

```
start scheduleView.html          # Windows
```

## 画面の構成

| 領域 | 内容 |
| --- | --- |
| ツールバー | 開始日・単位（日ごと／週ごと）・期間（1〜36 か月）・倍率（×0.6〜×2.4）・週を月曜に揃える・**＋ 項目**・**－ 項目** |
| 状態チップ | 表示範囲／項目数／ブロック数／今日／選択中の内容 |
| 線表 | 左が項目欄（色・項目名・`＋`／`−`）、右がトラック（月帯・週や日の目盛り・点線グリッド・今日線） |
| 項目詳細 | 線表下の表。項目名・色・項目詳細・関連リンク・備考 |
| フッター | JSONダウンロード／JSON読み込み／初期例に戻す／全消去 |

## 項目とブロックの操作

### 役割の分担

| ボタン | 対象 |
| --- | --- |
| 上部の **＋ 項目**／**－ 項目** | **項目**（行）の追加・削除 |
| 行の `＋`／`−` | **その行の中のブロック**の追加・削除 |

- **＋ 項目** … 選択中の項目の直後に挿入（未選択なら末尾）。名前は `項目N`、色は 12 色パレット順、長さ 7 日のブロックが空いている位置に自動配置されます。
- **－ 項目** … 選択中の項目を削除（未選択なら末尾の項目）。項目名入りのトーストが出て、`Ctrl+Z` で戻せます。
- 行の `＋` … その行に 7 日分のブロックを追加し、選択状態にします。
- 行の `−` … **その行で選択中のブロック 1 個だけ**を削除します。ブロック未選択のときは削除せず「削除するブロックを線表でクリック選択してください」と案内し、その行の `−` は淡色表示になります。

### ブロック

| やりたいこと | 操作 |
| --- | --- |
| 追加 | トラックの空欄をダブルクリック（クリック位置にスナップ、長さ 7 日。既に埋まっている位置はトーストで断ります）／行の `＋` |
| 移動 | ブロック本体をドラッグ／`←` `→` |
| 伸ばす・縮める | ブロックの左右端をドラッグ／`Shift` + `←` `→`（右端を 1 単位） |
| 削除 | `Del` または `Backspace`／行の `−`（その行で選択中のブロックのみ） |
| 選択 | ブロックをクリック（項目詳細テーブルの該当行もハイライト） |
| 項目だけ選択 | 項目行の何もない部分をクリック（ブロックは未選択のまま行が強調） |

ブロック同士は重なりません。移動・伸縮は他のブロックの空き範囲内に自動で収まり、単位が「週ごと」のときは 7 日単位のスナップ・最短 7 日になります。

ブロック面は**中央に日数**、その左に項目名を出します。左右端 8px が伸縮の掴み域なので、日数は中央に置いて右端を掴みやすくしています。幅が狭く項目名を 2 文字も収められないブロックは項目名を伏せ、**日数だけを左寄せ**（ブロックの左端から 10px）に出します。中央寄せのままだと狭いブロックでは右半分がからっぽになり、掴めるはずの右端が掴みにくそうに見えていました（狭くないブロックは中央のままなので右端 8px の掴み域には重なりません）。項目名は左の項目欄と項目詳細テーブルに出ます。ドラッグ中の日付読み出し（tip）は**掴んだ側の端**に出します（本体ドラッグ＝中央、左端＝左端、右端＝右端）。従来は常にブロックの左端アンカーで、幅 466px のブロックの右端を掴むと読み出しが 462px 左に離れていました。

### キーボード

| キー | 動作 |
| --- | --- |
| `Ctrl` + `Z`（Mac は `Cmd` + `Z`） | undo |
| `Ctrl` + `Shift` + `Z` | redo |
| `←` `→` | 選択中ブロックを 1 単位移動 |
| `Shift` + `←` `→` | 選択中ブロックの右端を 1 単位伸縮 |
| `Del` / `Backspace` | 選択中ブロックを削除 |

入力欄にフォーカスがあるときはキー操作は通常の入力として扱われます。

## 項目詳細テーブル

線表の下にある表で、各行が項目に対応します。

| 列 | 挙動 |
| --- | --- |
| 項目名 | 編集すると線表の項目名に同期。`Enter` で確定 |
| 色 | 色ピッカーで変更、線表のブロック色に同期（HEX 表示つき） |
| 項目詳細 | 自由入力（複数行、入力に合わせて自動で高さが伸びる） |
| 関連リンク | URL を入力すると `↗` が現れ、新しいタブで開きます |
| 備考 | 自由入力（複数行） |

入力は自動保存されます。テーブルの行（入力欄以外）をクリックするとその項目が選択され、線表側にも反映されます。

関連リンクは `https://` `http://` `mailto:` `tel:` をそのまま使い、`docs.example.com/spec` のようにスキーマが無い場合は `https://` を補完します。空白や制御文字を含むなど URL として扱えない入力では `↗` は出ません。

## 表示設定

- **開始日** … 線表の左端の日付
- **単位** … 日ごと／週ごと（週ごとにすると 7 日スナップ・最短 7 日）
- **期間** … 1〜36 か月
- **倍率** … ×0.6〜×2.4（0.2 刻み）
- **週を月曜に揃える** … 週ごとの先頭を月曜に揃えます

開始日の変更や期間・単位の短縮で範囲に収まらなくなったブロックは、切り詰めるか削除され、件数をトーストで通知します（例：「期間短縮： 2件短く／1件削除」）。

## データの保存と受け渡し

- **自動保存**：`localStorage` のキー `scheduleView.v1` に保存されます（そのブラウザ・そのマシン限定）。ブラウザのサイトデータを消すと失われます。
- **JSONダウンロード**：`schedule-<開始日>.json` を保存（例 `schedule-2026-11-02.json`）。
- **JSON読み込み**：選んだ JSON で現在の状態を置き換えます（「読み込みました（項目 N件）」）。他のブラウザやマシンへはこれで受け渡してください。
- **初期例に戻す**：サンプルの 5 項目を復元。**全消去**：全項目を削除（どちらも `Ctrl+Z` で戻せます）。

JSON の形：

```json
{
  "startDate": "2026-11-02",
  "unit": "week",
  "months": 3,
  "alignMonday": true,
  "zoom": 1,
  "items": [
    {
      "name": "調査",
      "color": "#7fa9d3",
      "detail": "顧客ヒアリング結果をまとめる。",
      "links": "docs.example.com/spec",
      "notes": "11/15 までに一次版",
      "blocks": [{ "id": "x1-abcde", "start": 0, "len": 7 }]
    }
  ]
}
```

`start` は開始日からの日数（0 始まり）、`len` は日数です。項目の `id` は JSON に含めず読み込み時に採番し、ブロックの `id` は保持します。

## 制限・既知の挙動

- データ保存はブラウザ内のみ（サーバー同期・複数人同時編集はしません）
- 幅 760px 以下ではレイアウトを簡略化して表示（スマホでも扱えますが、ドラッグ操作は広い画面向け）
- undo / redo のときに項目の内部 ID が振り直されます。内容・表示・undo の結果は正しく、JSON の書き出し・読み込みにも影響はありません
- ブロックのラベルは項目名のみ（ブロックごとの名前付けはしません）

## ファイル構成

| パス | 種別 |
| --- | --- |
| `scheduleView.html` | 成果物（このファイルだけで動作） |
| `README.md` | 使い方 |
| `worklog.md` | 作業記録（実測値と時刻） |
| `memo.txt` | 要件メモ |
| `scratch/` | 検証ハーネスとスクリーンショット（**成果物ではありません**） |
| `temp.logs/` | 実行ログ（一時） |

`scratch/` の検証ハーネス（`cdp.js` / `dtbtn.js` / `dtprobe.js` / `dtshot.js` / `dtstats.js` / `dtdel.js` / `dtdaysprobe.js` / `dtnarrowpx.js`）は Node.js で動きます。実行すると headless Chrome を起動し、実マウス入力で操作した結果を DOM 状態・実ピクセルと突合します。成果物には一切組み込みません。

```
node scratch/dtstats.js
node scratch/dtdel.js          # 削除ボタン廃止＋日数中央寄せ＋狭いブロックの左寄せ＋tip 位置（53 検査）
node scratch/dtdel.js --centre-before   # negative control（左寄せ前のコピーを検査）
node scratch/dtdaysprobe.js    # ブロック内の幾何と tip の距離を実測（合否なし）
node scratch/dtnarrowpx.js     # 撮れた PNG で狭いブロックの右半分に文字インクが無いことを確認
```

最終検証（2026-11-11 20:33〜20:42 JST 実行）：`dtdel.js` PASS 53 / FAIL 0（10,418ms）。negative control は左寄せ前で PASS 50 / FAIL 3（FAIL は左寄せ検査 I1〜I3 のみ）、日数中央寄せ前で PASS 36 / FAIL 17、さらにその前（ブロック内 `−` 残存）で PASS 26 / FAIL 27。狭いブロックの日数は盒左端から 10px・盒の右半分は 0 画素（変更前 148 画素）、狭くないブロックは中心偏差 0px のまま。既存回帰は `dtprobe.js` PASS 45 / FAIL 0 / SKIP 0、`dtshot.js` PASS 16 / FAIL 0。`dtbtn.js` は PASS 20 / FAIL 1（937ms）で、唯一の FAIL は廃止したブロック内 `−` をまだ見に行く検査（T6）です。詳細は `worklog.md`。
